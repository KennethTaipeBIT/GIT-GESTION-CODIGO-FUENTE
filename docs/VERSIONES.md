# Historial de Versiones - Catalogo de Productos

Nomenclatura: `MAYOR.MENOR.PARCHE`

- **MAYOR**: se agrega o elimina funcionalidad / cambios de alto impacto. Reinicia MENOR y PARCHE.
- **MENOR**: modificaciones de mediano impacto. Reinicia PARCHE.
- **PARCHE**: forma, apariencia o impacto menor.
